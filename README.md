# Nicole Xiao — Data Analytics Portfolio

**Live portfolio:** https://baobao0517.github.io/

An independent data analytics portfolio featuring two New Zealand projects. Each uses official data, reproducible methods and decision-oriented insights.

## Featured projects

| Project | Focus | Live dashboard | Source |
|---|---|---|---|
| NZ Tourism Commercial Insights | Australia, China and USA visitor composition, spending and market opportunity, using MBIE IVS survey-weighted data | [Open dashboard](https://baobao0517.github.io/nz-tourism-commercial-insights/) | [Repository](https://github.com/baobao0517/nz-tourism-commercial-insights) |
| NZ Education Participation & Outcomes Insights | Regional attendance, NCEA Level 2+ attainment, persistent gaps and learner-group analysis, using Education Counts | [Open dashboard](https://baobao0517.github.io/nz-education-participation-outcomes/) | [Repository](https://github.com/baobao0517/nz-education-participation-outcomes) |

## Portfolio approach

**Frame the question → Validate the data → Analyse differences → Translate findings into decisions.**

The landing page is a lightweight HTML and CSS site with no build dependencies. Its chart previews come directly from real published project artifacts and link to the source repositories.
